# Node-Js-File-Renamer
A Node.js utility script to bulk rename files inside a directory by replacing specific text strings automatically.
## Features

- **Automated Directory Scanning:** Reads file names inside target folders using Node.js file system.
- **String Replacement (`replaceAll`):** Instantly targets specific text patterns in filenames and replaces them with user-defined strings.
- **Preview Mode:** Includes a preview flag (`preview = true`) to test rename operations in the console before applying actual disk changes.
- **Batch Processing Support:** Works seamlessly with batch scripts (`rename.bat`) for quick execution.
